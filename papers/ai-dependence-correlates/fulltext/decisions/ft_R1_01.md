| Код | Что значит |
| --- | --- |
| `=` | согласен с ИИ |
| `+` | подходит: есть мера зависимости от ИИ, наш коррелят и корреляция нулевого порядка между ними |
| `-1` | не подходит: обзор, комментарий, теоретическое, протокол, качественное без количественной меры зависимости |
| `-2` | не подходит: нет меры зависимости от ИИ (только частота, принятие, доверие, грамотность, технострес, страх ИИ; over-reliance только в эксперименте) |
| `-3` | не подходит: социальные роботы, ИИ лечит или выявляет зависимость, ИИ как инструмент анализа, «dependence» в другом смысле |
| `-4` | не подходит: есть мера зависимости, но нет ни одного нашего коррелята |
| `-5` | не подходит: нет корреляции нулевого порядка (только пути SEM, многомерные β, частные корреляции, HTMT) |
| `-6` | не подходит: та же выборка, что в другом отчёте (связать) |
| `-7` | не подходит: другое — напишите почему |
| `?` | пока не решил (до закрытия файла нужно решить) |

Корреляции ИИ брал из текста, но выписываться они будут на следующем этапе по оригиналу — здесь решаем только «подходит / нет» и причину. Таблица корреляций часто в конце статьи или в приложении.
